# Классификация текстов с помощью алгоритма k ближайших соседей (k-NN)

## Описание проекта
Курсовая работа по дисциплине «Технологии машинного обучения и анализа данных» на тему реализации алгоритма классификации с помощью k ближайших соседей для задачи бинарной классификации электронных писем на спам и не спам.

## Цель работы
Реализация алгоритма k-NN для решения задачи классификации текстовых данных и исследование влияния параметров алгоритма на качество результатов.

## Задачи исследования
1. Изучить теоретические основы метода ближайших соседей
2. Исследовать влияние ключевых параметров алгоритма
3. Реализовать программную модель алгоритма k-NN
4. Провести экспериментальное исследование и оценить эффективность метода

## Используемые технологии и библиотеки
- **Python** - основной язык программирования
- **pandas** - обработка и анализ данных
- **scikit-learn** - машинное обучение и предобработка
- **imblearn** - балансировка данных (SMOTE)
- **matplotlib** - визуализация данных
- **joblib** - сохранение моделей

## Методология

### Предобработка данных
- Очистка текста от стоп-слов, пунктуации, чисел и гиперссылок
- Нормализация регистра
- Удаление дубликатов и аномальных значений

### Векторизация текста
- Использование TF-IDF с параметрами:
  - `max_features=33000`
  - `ngram_range=(1,2)`
  - `stop_words='english'`

### Балансировка данных
- Применение метода SMOTE для устранения дисбаланса классов

### Модель классификации
- Алгоритм k ближайших соседей
- Оптимальные параметры:
  - `n_neighbors=3-7`
  - `metric='cosine'`

## Результаты
- Accuracy на тестовой выборке: **0.97**
- F1-score: **0.96**
- Устойчивость модели подтверждена кросс-валидацией
